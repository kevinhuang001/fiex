# Fiex 插件系统技术规格（提案）

> **状态：设计规格 / 尚未实现。** 基线：Fiex v0.2.7，PR #3 合并提交 `d3dbbe20`。以下 API、路径与示例均为拟定接口，不表示当前代码已支持。文档版本：**Draft 0.1（2026-10-22）**。
>
> 约定：**MUST / 必须** 为不可妥协的兼容要求；**SHOULD / 应当** 可在记录理由后偏离；**MAY / 可选** 为可选扩展。标有 `v1` 的消息均指提案中的协议版本，尚未发布。

## 目标

将 WebDAV、SMB 从内核迁为**连接插件**，将 Git 迁为**功能插件**，并允许第三方以同等能力扩展 Fiex。**连接/功能是展示和分发分类，而非互斥的运行时类型**：任意插件可以同时贡献 VFS 虚拟目录、右键菜单、工具栏与面板。

统一职责：

- **插件**：协议适配、认证交互、远程或虚拟目录的节点/内容访问、可选变化检测及声明式 UI/命令。
- **内核**：VFS 路由与目录展示、**全部缓存与同步策略**、跨文件系统传输、冲突仲裁、任务与取消、UI 渲染、权限、凭据与进程监管。
- **官方插件不享受特权**：官方与第三方同一包格式、同一 IPC、同一宿主 API、同一权限校验。内核不允许出现 `webdav` / `smb` / `git` 等官方插件 ID 的业务分支。
- **插件是独立操作系统进程**；初版提供 Rust SDK，但协议保持语言无关。Fiex 不安装 Python/Node.js 运行时；使用这些语言的作者自行交付可启动的完整程序。

## 设计的不变量

1. 没有插件时，本地文件浏览、文件操作及应用启动仍可工作（本地文件系统适配器是内核基础设施）。
2. 插件可同时注册连接实例和功能贡献，包括**功能插件提供虚拟目录**。
3. 浏览目录 ≠ 下载内容 ≠ 启用同步；未缓存文件不得用真实的零字节文件占位。
4. 缓存与同步引擎只存在内核，插件仅实现资源能力及可选加速接口；不能绕过内核自行改变同步基线。
5. 不依赖单个全局取消标记：所有长操作由 `taskId` 精确寻址。
6. 所有插件调用都经权限与上下文校验；独立进程**并不等于**操作系统沙箱。
7. 协议具备版本、结构化错误和契约测试，第三方无需链接内核源码。

## 范围和非目标

第一阶段交付核心协议、VFS、内核缓存与离线钉选、只读/读写扩展、声明式 UI、任务中心及迁移的三款官方插件。双向同步只对具有足够写入一致性能力的挂载开放。自定义 WebView 面板、插件市场、真正的 OS 级强制沙箱可分阶段提供，不得以缺乏沙箱为由宣称插件安全。

## 与当前架构的关系

当前代码仍在 `src-tauri/src/remote.rs` 中实现 WebDAV/SMB，`git.rs` / `git_remote.rs` / `git_history.rs` 中实现 Git，`desktop.rs` 中做特殊路由，`src/hooks/useActivity.ts` 管理前端活动状态。详见 [现有架构说明](../ARCHITECTURE.md)。本目录只记录**目标架构、实现契约与迁移计划**，不能当作当前功能说明。
