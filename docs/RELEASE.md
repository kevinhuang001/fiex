# Fiex 0.2.5

- 标签页保存各自的一面板或双面板布局、目录和导航历史。双面板支持调整宽度，两个面板均可浏览、预览和操作文件。
- 文件夹切换不再自动聚焦搜索框；工具栏、标签页、路径栏和面板视觉层级得到统一，界面说明文案精简。
- 状态中心在列表中展示操作摘要，点击“查看详情”可查看时间、耗时与完整结果；底部工作区改为紧凑的文件停靠栏。
- 启动时移除中文 Web 字体下载，延后搜索索引预热；大目录列表减少重复元数据查询和排序分配。
- 修复双面板目录监视相互覆盖、一个面板的搜索取消另一个面板的搜索，以及目录删除后索引残留子文件的问题。
- WebDAV/SMB 连接保存前先创建本地目录，避免目录创建失败留下无效配置。
- 文件冲突处理、跨窗口拖拽、Git 远程推送和拉取、文件系统驱动集成来自本次合并的功能更新。

提供 macOS Apple Silicon 和 Intel DMG、Windows EXE 和 MSI、Linux DEB、RPM 和 AppImage。
