# Fiex 0.2.6

- 标签页改为贴住下边缘、上圆角下直角的样式；双面板路径栏会随宽度压缩，右侧面板新增独立搜索框。
- 侧边栏移除顶部标题和收藏 `+`，新增“连接”分组，WebDAV/SMB 连接从“设备”移入；修复右键菜单被主面板遮挡以及“从侧栏移除”无效的问题。
- 设置中的快捷键预设卡片不再被压缩裁切；区域顺序拖拽增加跟随指针的水平预览浮层，不遮挡目标行、不推挤下方项目。
- 标签新增色相/饱和度取色器、十六进制输入和 20 色预设，自定义颜色会保存在本地。
- 双面板支持双向拖拽移动文件和文件夹；聚焦面板增加淡背景；源代码管理面板紧贴工具栏按钮弹出。
- 修复双面板路径栏在窄宽度下搜索框、面包屑和关闭按钮相互挤压的问题。

提供 macOS Apple Silicon DMG、Windows EXE 和 MSI、Linux DEB、RPM 和 AppImage。
