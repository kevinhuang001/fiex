# 当前限制

以下内容描述 Fiex 当前版本的边界，不代表未来计划。具体变化请查看对应 Release。

- Fiex 还不是完整的 Finder 替代品；操作系统级网络磁盘挂载、系统 Quick Look 插件和全盘索引不在当前范围内。
- WebDAV 与 SMB 插件提供 Fiex 内的虚拟连接，不会创建操作系统级挂载点。
- Core 本地搜索实时遍历目录，不使用持久化索引；每次查询最多返回 500 项。
- Btrfs、APFS 和 HFS+ 的内置回退读取器只读；加密 APFS 不受回退读取支持。系统有原生驱动时优先使用系统驱动。
- 媒体预览取决于系统 WebView 编解码器；支持情况会因平台和安装环境不同而异。
- 跨卷移动通过“复制成功后删除来源”完成，速度和失败行为受源卷、目标卷和系统权限影响。
- 文件操作撤销与剪贴板状态属于 Fiex 当前会话。
- Linux 视觉模糊效果需要桌面合成器支持。
- 安装包没有商业代码签名证书。

插件的权限和平台沙箱边界见[插件权限与安全边界](/reference/security)。
