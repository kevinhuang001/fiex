# 当前功能边界

这些说明用于帮助你判断 Fiex 当前能做什么。具体平台和版本差异请查看对应 Release 说明。

## 文件浏览与搜索

- Fiex 还不能替代 Finder/Explorer 的全部系统功能；全盘后台索引、Quick Look 扩展和 OS 级网络磁盘挂载不属于当前能力范围。
- Core 搜索实时遍历文件夹，不使用持久化内容索引；单次查询最多返回 500 项。访问权限、忽略规则和目录规模会影响结果与用时。
- 文件夹信息面板不会默认递归扫描整棵目录树计算总大小。

## 外接和虚拟文件系统

- WebDAV、SMB 和其他连接插件展示 Fiex 内的虚拟位置，不会自动创建操作系统挂载点。
- 虚拟位置可执行的列举、读取、写入、移动、删除和预检由对应 provider 的运行时能力决定；不保证与本地磁盘一致。
- Core 提供的 Btrfs/APFS/HFS+ 回退读取器为只读，且并非每个平台/构建都启用。加密 APFS 不属于回退读取器支持范围；系统原生驱动可用时优先使用它。
- USB 文件系统的读取依赖平台驱动和构建配置；未挂载或驱动不可用时，Fiex 不承诺直接访问设备。

## 文件操作

- 跨卷移动需要先复制成功再移除源文件。大型传输可能较慢，移除源文件失败时可能保留两份。
- 撤销历史只覆盖当前运行中的部分操作，不能保证插件和系统级操作都可撤销。
- Trash “放回原处”依赖系统/来源记录及原位置存在；不同来源项目可能需要选择其他还原位置。
- 永久删除绕过废纸篓，通常无法恢复。

## 预览与平台

- PDF、文本/代码和常见图像可通过 Fiex 内置预览器处理；视频和音频预览依赖系统 WebView 编解码器。
- Windows/Linux 应用入口受系统应用枚举能力影响；macOS 的应用目录与系统应用 bundle 行为不同。
- Linux 模糊透明效果依赖桌面合成器。
- 正式安装包当前没有商业代码签名证书；操作系统可能显示来源/安全提示。

如需具体操作建议，查看[问题排查](/user-guide/troubleshooting)；协议权限边界见[插件安全](/reference/security)。
