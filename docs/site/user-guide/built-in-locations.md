# 常用位置、设备与废纸篓

## Applications（应用程序）

侧边栏在三个平台上都提供“应用程序”入口，但平台展示方式不同：macOS 浏览系统应用目录；Windows 和 Linux 展示平台应用列表。Core 还提供用户管理的应用条目和文件夹映射；系统应用条目不可在 Fiex 中删除。用户数据与导入资源保存在 Fiex 管理的位置，不等同于修改操作系统应用目录。

## Recent（最近使用）

Recent 是近期文件的虚拟视图。打开后会在列表中显示，不会把它变成磁盘上的独立副本。从 Recent 中移除只清理这条最近记录，不移动或删除真实文件。

## Trash / Recycle Bin（废纸篓 / 回收站）

Fiex 为系统废纸篓或回收站提供虚拟浏览入口。在 macOS 与 Linux 上，项目可以直接在 Fiex 中浏览和恢复；Windows 使用系统回收站接口。可使用项目菜单恢复、永久删除或清空。系统保护、挂载状态和权限可能影响某些项目的操作；遇到拒绝时先根据错误提示检查系统权限。

## USB 与可移动磁盘

Fiex 会列出系统识别到的可移动卷，并显示文件系统、容量和弹出入口。可移除卷优先使用操作系统原生文件系统驱动；写入能力、权限和写保护由操作系统在实际操作时决定。

只有当系统没有可用原生驱动时，Fiex 才提供 Btrfs、APFS 或 HFS+ 回退浏览器。回退视图只读；加密 APFS 不受回退读取支持。弹出磁盘前应先停止正在进行的文件操作。
