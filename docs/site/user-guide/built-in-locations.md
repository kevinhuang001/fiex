# 常用位置、应用与废纸篓

Fiex 边栏中的内置位置把常用系统入口放在同一个窗口里。位置的内容和可用命令会因操作系统与文件系统能力不同而变化。

## 常用位置与收藏夹

侧边栏可以显示主目录、桌面、文档、下载、收藏夹、标签和设备。单击条目进入；收藏夹适合保存常用文件夹，不会复制或移动该文件夹。

将文件夹拖到收藏区域，或使用菜单中的“添加到收藏夹”来固定它。删除收藏只移除边栏中的快捷入口，不删除磁盘上的文件。

## 最近使用

“最近”显示 Fiex 最近访问的文件或位置映射。右键选择“从最近删除”只会移除这条最近记录，不会移动、删除原始文件，也不会影响文件夹本身。

若项目已被移动或删除，最近列表中的入口可能失效；请从实际位置重新打开它。

## 应用

“应用”用于从 Fiex 浏览系统识别到的应用入口：

- macOS 可显示系统应用目录中的应用。
- Windows 和 Linux 显示当前 Core 能枚举到的系统应用入口，具体结果受桌面环境影响。

应用入口不是普通文件夹中的可执行文件集合。某些应用包的 URI、名称和在 Finder/桌面环境中的展示名由系统返回，因此可能不同于磁盘上的简单文件名。

用户导入的应用或快捷方式放入 Fiex 的私有 Applications 目录。Core 只接受可识别的应用类型，并按系统平台限制导入方式。系统自带的应用可以启动或在虚拟目录中组织；Fiex 不会卸载、删除或导出系统应用。Applications 里的文件夹和名称以界面展示的树形结构为准。

不同系统可识别的入口不同：

| 系统    | 系统应用                    | 可导入的常见用户应用入口                              |
| ------- | --------------------------- | ----------------------------------------------------- |
| macOS   | 系统应用目录中的应用 bundle | .app bundle、Finder alias 和实现支持的可执行文件      |
| Windows | Core 枚举到的系统应用入口   | 可识别的 .lnk 快捷方式和可执行文件                    |
| Linux   | Core 枚举到的桌面应用入口   | 有效的 .desktop 文件、AppImage 和实现支持的可执行文件 |

导入 bundle 或快捷方式时，Fiex 可能会复制、封装或生成自己的启动入口；原件是否保留取决于类型和平台。应用目录只用于启动和整理，不是软件安装器。

## 废纸篓

在 Fiex 的废纸篓位置查看可访问的系统回收项目。选择项目后使用“还原 / 放回原处”尝试恢复到原路径；如果原位置不存在、磁盘已断开、系统不提供原始路径信息或项目由其他应用删除，恢复可能失败。

对无法还原到原处的项目，可使用界面提供的其他还原位置流程。该操作需要你选择目标目录。不要把“从 Fiex 删除的文件可以还原”理解为任何来源的项目都一定能找回原路径。

Windows、macOS 和 Linux 的系统 Trash 后端和身份不同。macOS 若因系统隐私权限无法读取废纸篓，Fiex 会提示检查“系统设置 → 隐私与安全性 → 完全磁盘访问权限”；启用后通常需要重启应用。不要把某个平台可用的还原路径推断为其它平台也相同。

永久删除会绕过废纸篓，通常不可恢复。请查看[删除操作说明](/user-guide/file-operations#放入废纸篓与永久删除)后再执行。

## 外接磁盘和移除卷

外接卷会在系统已挂载且当前账户可访问时显示。退出前先关闭正在读写该卷的窗口或操作；若系统提示卷忙，先等待传输结束，再通过 Fiex 或操作系统安全弹出。

USB 文件系统的支持取决于平台驱动和构建配置。若设备没有挂载，Fiex 不能保证直接读取它；请先在系统设置/磁盘管理中检查设备状态。

优先使用操作系统已挂载的文件系统驱动。只有特定文件系统没有系统驱动时，发行版才可能提供只读回退浏览；回退不等于可写挂载。加密卷和不同驱动/权限组合需以当前平台提示为准。

## 虚拟位置与普通磁盘路径

Recent、Applications、Trash 和插件连接都可能以虚拟文件系统方式呈现。虚拟位置中的项目可以在 Fiex 内浏览和操作，但不一定对应可复制到终端的普通文件路径。操作是否可用由该位置公布的能力决定。

## 状态中心与错误

复制、移动、远程缓存和其它较长任务会在状态中心显示进度或结果。点击任务可查看来源、目标和错误详情；可取消的任务会提供停止入口。文件系统权限、插件连接和系统位置错误会显示具体原因。日志是帮助排查问题的诊断信息，不是文件操作成功与否的唯一依据。遇到问题时参见[问题排查](/user-guide/troubleshooting)。
