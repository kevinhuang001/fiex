# 本地终端与 SSH 连接

Fiex 提供一个内置本地终端面板，也可调用系统已安装的终端应用。SSH 连接由可选连接插件提供；内置本地终端本身不会连接远程主机。

## 使用内置终端

点击浏览窗口底部的终端入口打开面板。它在当前本地目录启动 shell；当当前位置是无法映射成本地路径的虚拟位置时，Fiex 会回退到本地用户目录。终端面板支持多个会话标签，关闭面板与结束 shell 会话是不同操作，按界面状态判断当前会话是否仍在运行。

终端字体和字号在设置中调整。字体列表由 Fiex 提供，不必打开系统字体选择器。

## 在系统终端中打开目录

使用工具栏或目录菜单中的“在终端中打开”。Fiex 会列出当前系统检测到的终端，可在设置中选择默认项。系统终端是否能打开特定虚拟位置取决于该位置能否提供本地目录路径；不能映射时使用 Fiex 提示的回退位置。

## 连接 SSH

SSH 入口由已安装的连接插件注册。安装后，从连接入口选择对应插件、填写服务器和账号信息，并按提示审查它申请的网络或命令权限。打开连接时，Fiex 将显示该插件提供的连接视图；这与内置本地 shell 不同。

Core 负责宿主视图和插件连接路由，不内置 SSH 凭据迁移或远程 shell fallback。插件可能依赖系统 OpenSSH 或提供自己的协议实现；具体认证方式、密钥代理、ProxyJump 和 ~/.ssh/config 支持以插件说明为准。不要在普通插件设置或日志中粘贴私钥、密码或 token。

## 常见问题

- **终端没有打开**：检查系统终端是否安装、当前位置是否仍可访问，并查看状态中心错误。
- **虚拟目录中的终端工作目录不对**：该目录可能没有对应的本地路径；在本地目录中打开终端，或使用插件提供的远程连接视图。
- **SSH 连接类型不存在**：检查提供连接能力的插件是否已安装并启用。
- **权限被拒绝**：检查插件授权、服务器地址和账号状态。Core 的文件 API 权限不等于 SSH 服务器的远程账户权限。

插件安装和权限说明见[安装插件与连接服务](/user-guide/plugins-and-connections)；插件 IPC 和安全边界见[开发者文档](/developer/plugin-development)。
