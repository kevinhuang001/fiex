# 认识主窗口与浏览文件

本页说明如何找到目录、在多个位置间切换，以及按自己的习惯查看文件。

## 浏览一个目录

从左侧边栏选择常用位置，或在文件区域双击文件夹进入。点击工具栏的上一级按钮返回父目录。地址栏显示当前路径；点击路径栏可编辑位置，选中路径后复制即可粘贴到其他应用。

![Fiex 文件浏览窗口](/screenshots/file-browser-list.png)

### 左侧边栏

边栏可显示常用位置、收藏夹、标签、设备和插件连接。单击位置即可进入。需要固定经常使用的目录时，可将文件夹拖到收藏区域，或使用该目录的上下文菜单添加到收藏夹。边栏具体区块取决于系统和设置。

### 标签页与双面板

- 新开标签页后，可在不同工作内容之间切换。每个标签保存自己的浏览位置。
- 点击双面板按钮显示第二个浏览区域。两个面板可以分别浏览不同目录。
- 点击某个面板后，它成为活动面板；顶部排序和分组控制只作用于活动面板。
- 新建的第二个面板会从最近访问过的位置开始。之后各目录仍按该目录自己的展示偏好恢复。
- 关闭标签页时，若关闭最后一个标签，Fiex 会打开设置里选定的起始页。

## 选择展示方式

从工具栏的视图菜单选择一种展示方式：

| 视图 | 适合用来做什么 |
| --- | --- |
| 列表 | 查看名称、修改时间、大小等列，并按列排序。可调整列宽。 |
| 图标 | 浏览文件缩略图或图标，适合图片和视觉素材。 |
| 列 | 沿目录层级逐列浏览，查看相邻层级时不必反复返回。 |
| 画廊 | 以较大的预览检查当前选择的图片或其他可预览文件。 |

排序决定文件的先后顺序；分组会把同类文件放在一起。可按名称、修改时间、大小等字段排序，并选择升序或降序。某些字段对文件夹没有意义时，目录项的顺序会按界面规则处理。

Fiex 会为目录记住视图与排序/分组偏好。若想让新目录都从常用方式开始，进入设置修改默认展示选项；若只需调整当前目录，直接在工具栏修改即可。

## 在文件夹中快速定位

可以在当前浏览位置开始输入名称来过滤/查找，也可以使用工具栏搜索框进行更完整的名称或内容搜索。搜索范围和结果说明见[搜索与预览文件](/user-guide/search-preview)。

## 标签与工作区

标签用于切换浏览上下文；工作区用于暂存稍后处理的文件和文件夹。通过上下文菜单中的“添加到工作区”收集项目。工作区不会移动或复制原文件；要查看文件仍可从工作区打开其位置。
