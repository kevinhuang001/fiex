# 浏览、视图与导航

## 浏览视图

Fiex 提供列表、图标、分栏和画廊视图。图标视图采用固定网格布局，文件名最多显示两行，并按网格位置对齐。列表视图可显示并排序多列信息；分栏视图用于逐级浏览目录；画廊视图用于视觉浏览。

可按文件种类、扩展名、修改时间或大小分组，并调整排序方向。视图和显示偏好保存在应用设置中。

## 侧边栏

侧边栏可以包含常用位置、收藏、Finder 标签和设备。进入“设置 → 侧边栏”可以调整这些分组的顺序，并隐藏不需要的常用位置。把文件夹拖到收藏区域可将它加入收藏。

macOS Finder 标签会以彩色标记显示在支持的视图中；可通过右键菜单设置系统颜色或自定义标签名。点击侧边栏标签可筛选当前目录，再次点击可清除筛选。

## 地址栏和历史

点击地址栏可编辑当前位置；路径文本会被选中，便于复制或输入路径。可以通过后退、前进、上级目录、标签页和收藏夹切换位置。目录变化由文件监视通知刷新。

Fiex 的内部虚拟位置使用自己的位置标识。虚拟位置的路径显示、面包屑和地址栏导航都由 Core 统一解析；不要把这些位置当成系统磁盘路径。

## 终端与外部应用

工具栏的“在终端中打开”会检测已安装终端并允许选择默认终端。文件或文件夹也可通过工具栏或右键菜单交给 VS Code 等已检测到的应用打开。对文件使用右键菜单中的“Open With”子菜单，可以直接选择系统检测到的应用；“选择其他应用…”会打开可搜索的应用列表。
