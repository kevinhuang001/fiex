# 问题排查

先确认你使用的 Fiex 版本：打开“关于”或查看安装包版本号。不同平台和版本的系统集成能力会有差异。

## 文件或目录打不开

1. 检查目标路径是否仍存在，外接设备是否已连接并挂载。
2. 确认当前用户有读取权限。
3. macOS 上检查“系统设置 → 隐私与安全性 → 完全磁盘访问权限”，按需允许 Fiex 访问受保护位置。
4. 对插件连接，确认账号授权和网络连接有效。
5. 若只有一个文件打不开，尝试从系统文件管理器或“打开方式”检查文件是否可用。

## 插件无法启用或功能不可用

- 打开“插件设置”，确认插件已安装并处于启用状态。
- 查看授权状态；如果必要权限未批准，重新进入插件授权或调整权限。
- 看清插件支持的平台和要求的 Fiex 版本。协议版本不匹配的插件不能通过修改名称或版本号解决，需要使用相容构建。
- 本机手动复制的插件可能默认停用；在设置中显式启用并审查权限。
- 如果错误只在某项操作出现，确认插件是否请求了与该操作相符的权限。

## 搜索没有找到文件

确认搜索范围和搜索模式正确。Fiex 实时遍历目录而非搜索完整后台索引；搜索可能需要时间，最多显示 500 项。检查忽略规则、目录权限以及文件是否为二进制内容。

## 预览空白或无法播放

确认该类型在 Fiex 的支持范围内。PDF、文本和常见图片通常可以预览；部分音视频格式取决于系统编解码器。选择“打开方式”将文件交给其他应用。

## 放回原处没有成功

Fiex 会尝试用系统记录的原始路径还原。来自其他应用或其他磁盘的回收项目可能没有可用的原始位置记录；原位置已删除或设备未连接也会导致恢复失败。使用界面提供的目标位置流程，或先在系统回收站确认该项目是否仍可还原。

## 终端打不开

检查当前位置是否仍可访问，以及对应平台是否安装系统终端环境。虚拟目录不能总是映射为普通终端工作目录；遇到这种情况时，Fiex 会按当前实现选择一个本地工作目录。终端外观可以在设置中调整。

## 收集有用的故障信息

提交问题时请提供：

1. Fiex 版本、操作系统版本和处理器架构。
2. 出问题的位置类型：本地目录、外接卷、系统位置或插件连接。
3. 复现步骤和完整错误文本。
4. 是否只对某个文件/目录发生，以及换用系统文件管理器后是否仍可复现。

不要公开密码、访问令牌、个人文件内容或包含隐私的完整路径。项目问题入口：[GitHub Issues](https://github.com/kevinhuang001/fiex/issues)。
