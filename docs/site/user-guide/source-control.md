# 使用源代码管理

Git 功能由可选插件提供，不是每个 Fiex 安装都默认包含。需要使用时，在插件设置中安装兼容版本，并确保系统已安装插件要求的 Git 工具。

## 查看仓库状态

在 Git 仓库目录打开 Source Control 面板。可查看当前分支和变更数量；变更文件会按状态标记。没有仓库时，插件可提供初始化入口。Git 文件操作发生在本机仓库中，删除或提交前先确认当前仓库和工作区。

## 暂存与提交

1. 在变更列表选择文件并暂存，或使用插件提供的全选/全部暂存操作。
2. 确认只暂存了希望提交的文件。
3. 输入提交说明；如果仓库和全局配置都没有作者身份，先填写名称与邮箱。
4. 提交后检查面板中的结果和变更状态。

提交只包含已暂存文件。提交失败时，查看错误详情并确认草稿仍保留，再处理 Git 身份、权限或冲突。

## 浏览提交历史与远端

提交历史可按插件提供的分支或标签筛选。打开一个提交用于只读查看历史快照，不会把当前分支移动到该提交，也不会丢弃未提交修改。

若插件提供 push 或 pull，请先确认远端仓库地址和当前分支。Fiex 当前描述的 pull 可能限制为 fast-forward；拒绝或冲突时请使用熟悉的 Git 工具处理，不要假设插件会自动 rebase、覆盖或解决冲突。

Git 操作失败时先查看 Source Control 面板的原因与[问题排查](/user-guide/troubleshooting)。插件权限与生命周期见[插件与连接](/user-guide/plugins-and-connections)。
