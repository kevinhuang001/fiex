# 安装与首次启动

本页带你从下载走到打开第一个文件夹。首次启动后，Fiex 会显示文件浏览窗口；你可以先使用本机文件功能，不安装插件也能开始整理文件。

## 1. 下载并安装

打开 [Fiex 最新 Release](https://github.com/kevinhuang001/fiex/releases/latest)，选择与你的系统和处理器相符的安装包。Release 页面会列出该版本实际提供的文件；如果没有你的系统或架构，请查看该版本说明，不要改用来源不明的构建文件。

- **macOS**：下载对应的 `.dmg`，打开后按安装包说明将应用放到“应用程序”中。
- **Windows**：下载 `.msi` 或 `.exe` 安装包并按向导完成安装。
- **Linux**：选择 Release 提供的 `.deb`、`.rpm` 或 AppImage。桌面环境还需要满足 Tauri/WebKitGTK 等运行依赖。

首次运行时，操作系统可能询问是否允许打开从互联网下载的应用。先核对应用来自 Fiex 官方 Release，再按系统提供的选项继续。发行包当前不保证带有商业代码签名，因此系统提示可能因平台而异。

## 2. 打开一个文件夹

Fiex 启动后会按设置打开起始位置。点击左侧位置可切换目录；也可以点击地址栏输入路径，或按地址栏快捷键后输入路径。地址栏中的完整路径可以直接复制。

![Fiex 文件浏览窗口，展示侧边栏、路径栏、文件列表和底部状态栏](/screenshots/file-browser-list.png)

*图：当前 Fiex 文件浏览界面示例。目录名称、文件内容和可用位置会随你的电脑而变化。*

如果某个目录打不开：

1. 检查路径是否仍然存在，以及外接磁盘是否已连接。
2. 在 macOS 上，检查“系统设置 → 隐私与安全性 → 完全磁盘访问权限”是否需要允许 Fiex 访问受保护位置。
3. 在 Windows 或 Linux 上，确认当前账户有该目录的读取权限。
4. 再次尝试打开；如果问题只发生在一个位置，先用系统文件管理器确认该位置可访问。

## 3. 认识浏览窗口

- **侧边栏**：跳转到常用位置、收藏夹、标签、设备以及已启用的插件位置。可在设置中调整哪些区块显示。
- **标签页**：在不同目录间切换，而不丢失当前浏览位置。
- **分栏浏览**：打开第二个面板，在两个目录之间拖动或复制文件。排序按钮只影响当前活动面板。
- **路径栏**：查看当前路径，点击后可编辑或复制整条路径。
- **文件区域**：可切换列表、图标、列和画廊视图；分组、排序和列宽用于控制当前文件的呈现。
- **底部状态栏**：显示当前目录信息，并提供内置终端入口。点击终端按钮会打开底部面板。

每个目录可以记住自己的视图和排序设置。切换目录时，Fiex 会恢复该目录上次使用的展示方式；这不会改变文件本身。

## 4. 可选功能：插件

插件用于增加远程连接、额外预览或其他扩展能力。插件不是启动 Fiex 的前置条件。需要时，打开工具栏中的“插件”菜单，再进入插件设置；安装前请先查看它请求的权限。授权步骤见[安装插件与连接服务](/user-guide/plugins-and-connections)。

## 平台差异

macOS、Windows 和 Linux 都可浏览本地文件，但应用列表、废纸篓接入、外接卷和媒体解码取决于平台服务。Fiex 的应用列表在 macOS 显示系统应用；Windows/Linux 显示 Core 当前枚举到的应用入口。部分视频或音频格式需要系统 WebView 支持相应编解码器。

安装或启动遇到问题时，参见[问题排查](/user-guide/troubleshooting)。
