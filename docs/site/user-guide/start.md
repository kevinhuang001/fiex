# 安装与首次启动

## 下载

前往 [Fiex Releases](https://github.com/kevinhuang001/fiex/releases/latest)，下载与你的操作系统和处理器架构匹配的安装包。当前发布流水线为 macOS、Windows 和 Linux 构建安装包；不同版本的具体资产以 Release 页面为准。

下载时应选择 Release 页面中明确标注平台和架构的文件。不要把开发构建产物当作正式安装包。

## 首次启动

1. 从 Release 页面下载对应安装包。
2. 按操作系统常规流程安装并启动。
3. 初次使用时先浏览本地目录，确认文件权限和系统挂载状态符合预期。
4. 需要扩展功能时，再从插件入口查看可用插件并逐项授权。

Fiex 的正式安装包没有商业代码签名证书。操作系统可能显示来源或安全提示；请先确认安装包来自 Fiex 官方 Release 页面，再根据系统提示决定是否继续。

## 平台说明

- **macOS**：文件访问受当前用户权限和 macOS 隐私设置控制。访问受保护位置失败时，Fiex 会在适用场景中提示前往“完全磁盘访问权限”设置或改用 Finder。
- **Windows**：系统应用入口显示 Windows 应用列表；可移除卷优先使用 Windows 已挂载的文件系统驱动。
- **Linux**：需要安装 Tauri 所需的 WebKitGTK、GTK 和系统开发依赖。模糊透明效果取决于桌面合成器。

媒体预览依赖系统 WebView 可用的编解码器；打不开的文件仍可以通过系统默认应用打开。

## 更新

从 [Releases](https://github.com/kevinhuang001/fiex/releases) 获取新版本，并按平台安装包说明更新。更新内容和已知限制以对应版本的发布说明为准。
