# 查看文件信息

选择文件或文件夹后，打开“信息 / Get Info”面板查看它的基本属性和可用的扩展信息。面板区分文件与文件夹，因此不会把子文件的统计数据误认为文件夹本身的元数据。

## 基本信息

根据所选对象和文件系统能力，面板可能显示名称、类型、大小、位置、创建/修改时间等字段。不同平台和不同文件系统能提供的属性不完全相同。远程或虚拟文件系统返回的信息由对应 provider 决定。

## 插件信息与按需计算

插件可在信息面板中声明自己的字段。字段会先显示名称和说明；其中标记为“打开时计算”的字段会在面板打开时请求结果，标记为“按需计算”的字段则先显示尚未计算状态。

对于按需字段：

1. 展开包含该字段的区块。
2. 点击字段旁的计算按钮。
3. 等待结果返回；如果该字段计算失败，面板会显示错误或重试提示。

Fiex 只请求你点选的按需字段。打开信息面板本身不会为了列出所有字段而启动每个插件。插件仍受用户授予的权限与当前选中文件范围约束。

## 文件夹统计

文件夹信息默认不会递归扫描整个目录树来计算“总大小”或子项数量。这样可以避免打开信息面板就遍历大量文件。若插件提供额外统计字段，字段是否自动计算由它的声明决定；按需字段需由你主动触发。

## 复制信息

需要把文件路径放到邮件或终端时，可在文件菜单中选择“复制路径”，或选中地址栏复制当前目录路径。并非所有虚拟位置都能还原成操作系统可直接访问的普通路径；VFS 项目应在 Fiex 内通过其位置打开。
