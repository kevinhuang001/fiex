# 文件信息与按需计算

“显示简介”面板分别展示文件或文件夹的元数据。Core 提供基础信息，匹配当前资源的插件也可以贡献自己的信息字段；插件字段会标明提供它的插件。

## 打开面板

在文件或文件夹的右键菜单中选择“显示简介”。面板打开时会读取字段定义，并自动计算标记为“打开时计算”的轻量字段。

## 按需计算

目录统计和插件声明的耗时字段默认显示“尚未计算”。点击字段旁边的“计算”后，Fiex 只请求该字段；面板显示计算状态，关闭面板会结束对应会话并取消仍在运行的任务。失败的字段可以重试。可用的字段会因文件类型、平台、资源来源及权限不同而变化。

| 计算方式   | 什么时候运行         | 常见用途                                         |
| ---------- | -------------------- | ------------------------------------------------ |
| 打开时计算 | 打开面板后自动计算   | 名称、类型、位置、大小、时间等基础属性           |
| 按需计算   | 用户点击“计算”后运行 | 遍历目录得到文件数量、递归大小或插件提供的校验值 |

## Core 字段

Core 会根据资源类型、平台和可用元数据提供字段。文件常见字段包括名称、类型、位置、扩展名、MIME 类型、大小、时间、只读状态、隐藏状态和权限。符号链接还可显示链接目标及目标是否存在；Unix 系统在属性可用时还可显示所有者、用户组、文件标识、硬链接数和实际占用空间。

本地文件夹的“目录统计”字段按需计算，可分别查看直接文件、直接文件夹、其他节点的数量，以及递归文件数、递归文件夹数、递归文件总大小、递归实际占用空间和符号链接数。文件系统/provider 不提供某项数据时，该字段可能显示为不可用。

## 插件字段

插件在 manifest 的 `extensions.info.sections` 中声明字段名称和计算时机。打开面板时，Core 使用已注册的字段描述，不会启动插件来逐个询问字段；需要计算时，Core 把精确的 section/field ID 交给对应插件的 `InfoProvider::compute`。结果以文本显示，面板提供复制按钮。字段读取、权限、缓存、取消和会话由 Core 管理。

开发者实现方式与 manifest 示例见[插件开发](/developer/plugin-development)。
