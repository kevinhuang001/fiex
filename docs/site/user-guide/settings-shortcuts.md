# 设置与快捷键

## 设置窗口

设置窗口提供可搜索的分类侧栏和分组卡片。可搜索分类名称并进入相应设置页；具体选项会随当前版本变化。

## 外观与侧边栏

外观可切换浅色、深色或跟随系统。侧边栏设置支持调整常用位置、收藏、标签和设备分组顺序，并可隐藏不需要的常用位置。

字体大小设置会同时影响文件名和图标视图图标。文件类型图标由 Material Icon Theme 提供；应用程序仍显示平台原生图标。

## 忽略规则

忽略项按使用目的分组管理：

- **显示忽略**：控制文件列表和本地搜索显示哪些条目；
- **复制/移动忽略**：复制或移动目录树时跳过哪些条目；
- **压缩忽略**：创建归档时排除哪些内容。

预设包含常见操作系统元数据和构建产物。修改规则后，确认编辑的是正确分组，因为“隐藏列表项”和“复制时跳过”会影响不同操作。

## 快捷键

在“设置 → 快捷键”中可以选择 macOS、Windows 或 Linux 风格预设，也可以单独重新录制某个动作。切换整套预设会重写所有快捷键绑定。

macOS 风格默认值：

| 动作                  | 快捷键                     |
| --------------------- | -------------------------- |
| Quick Look            | Space                      |
| 搜索 / 前往文件夹     | Cmd+F / Cmd+Shift+G        |
| 复制 / 剪切 / 粘贴    | Cmd+C / Cmd+X / Cmd+V      |
| 撤销 / 复制副本       | Cmd+Z / Cmd+D              |
| 新建 / 关闭标签页     | Cmd+T / Cmd+W              |
| 新建文件夹 / 新建文件 | Cmd+Shift+N / Cmd+Option+N |
| 重命名 / 打开         | Return 或 F2 / Cmd+Down    |
| 移到废纸篓            | Cmd+Backspace              |
| 后退 / 前进 / 上级    | Cmd+[ / Cmd+] / Cmd+Up     |
| 刷新 / 设置           | Cmd+R 或 F5 / Cmd+,        |

Windows 和 Linux 风格使用 Ctrl/Alt 组合键；常见默认操作包括 F2 重命名、Enter 打开、Delete 移入回收站、Alt+Left/Right 前进后退。可以在设置中查看当前实际绑定。

## 同步与连接

启用远程连接插件后，后台同步周期可以在相关设置中调整。是否可修改、默认值和连接级选项以当前插件版本显示为准。
