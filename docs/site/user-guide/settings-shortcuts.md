# 设置与快捷键

从工具栏打开“设置”。设置项按主题分区；具体可见选项可能随操作系统和 Fiex 版本改变。修改后请按界面提示应用或保存。

## 常用设置

- **常规**：选择启动时打开的位置，以及与启动行为相关的选项。
- **外观**：切换主题并调整文件浏览界面的显示方式。
- **侧边栏**：决定常用位置、标签、设备和插件位置是否显示。
- **文件显示**：设置默认视图、排序、分组及隐藏/忽略规则。每个目录还可以保存自己的展示方式。
- **标签**：创建、编辑和删除标签，并在文件上应用标签。
- **插件**：查看已安装插件、插件设置和权限。
- **快捷键**：查看当前键位方案，修改支持自定义的操作绑定。

Fiex 会将许多偏好保存在本机。若界面状态看起来没有更新，先关闭相关面板再打开，或重启应用后检查。

## 查找或更改快捷键

1. 打开“设置 → 快捷键”。
2. 使用搜索/分类找到要修改的操作。
3. 点击当前绑定并按下新的键位组合。
4. 按提示处理冲突并保存。

macOS 常用 `Command` 键，Windows/Linux 常用 `Ctrl` 键；实际绑定以设置页面显示为准。若按键在输入框中被截获，请先离开文本输入，再尝试对应快捷键。

常用默认快捷键如下。你可以在“设置 → 快捷键”查看当前绑定；改过快捷键或切换键位风格后，以设置页面为准。

| 操作               | macOS                            | Windows / Linux  |
| ------------------ | -------------------------------- | ---------------- |
| 快速查看           | `Space`                          | `Space`          |
| 搜索               | `Command+F`                      | `Ctrl+F`         |
| 前往文件夹         | `Command+Shift+G` 或 `Command+L` | `Ctrl+L`         |
| 复制 / 剪切 / 粘贴 | `Command+C / X / V`              | `Ctrl+C / X / V` |
| 新建文件夹         | `Command+Shift+N`                | `Ctrl+Shift+N`   |
| 重命名             | `Enter` 或 `F2`                  | `F2`             |
| 移到废纸篓/回收站  | `Command+Backspace`              | `Delete`         |
| 新建 / 关闭标签页  | `Command+T / W`                  | `Ctrl+T / W`     |
| 全选               | `Command+A`                      | `Ctrl+A`         |

## 终端字体

终端外观设置包含 Fiex 内置的 Nerd Font 选项。通过设置中的字体列表选择，不需要系统文件选择框。字体变化仅影响终端显示，不会修改文件内容。

## 重置某个目录的视图习惯

若只有一个目录使用了不合适的视图、分组或排序，先切换到该目录，在工具栏调整它的展示方式。其他目录会继续使用各自保存的偏好。要调整新目录的默认行为，再进入设置修改默认展示选项。
