# 选择、复制、移动与删除

本页按常见任务说明如何操作文件。右键菜单会根据当前位置、所选项目和平台显示适用的命令。

## 选择文件

- 单击选择一个项目。
- 使用 `Ctrl`（Windows/Linux）或 `Command`（macOS）逐个添加或取消选择。
- 按住 `Shift` 选择一段连续项目。
- 使用“全选”快捷键选择当前列表中的项目。可在“设置 → 快捷键”查看或修改绑定。
- 点击空白位置可清除选择；空白区域没有适用菜单时，Fiex 不会弹出浏览器自己的右键菜单。

快捷键会受系统平台和设置中的键位方案影响，因此以“设置 → 快捷键”显示的绑定为准。

## 新建文件夹

1. 进入要放置新文件夹的目录。
2. 点击工具栏“新建文件夹”，或在目录空白处打开菜单后选择该命令。
3. 输入名称并确认。

Fiex 会在当前目录创建文件夹。若当前位置是只读的虚拟位置，菜单可能不提供创建命令。

## 重命名

1. 选择一个文件或文件夹。
2. 按重命名快捷键，或在上下文菜单中选择“重命名”。
3. 编辑名称并确认。

Fiex 会保留扩展名的编辑体验，避免只想改文件名时不小心覆盖扩展名。批量重命名可在菜单中打开预览：先检查每个新名称，再应用更改。

## 复制与粘贴

1. 选择项目并复制，或使用“复制”菜单命令。
2. 打开目标目录。
3. 粘贴。

如果目标目录里已有同名项目，Fiex 会显示冲突处理选项。根据需要比较、替换、跳过或保留两个项目。保留两者会生成可区分的副本名称。

## 移动文件

在同一个 Fiex 窗口内，可将项目拖到另一个文件夹或另一个面板。拖到文件夹上时，目标文件夹会高亮；拖到收藏区域则会将文件夹加为收藏，不会移动它。拖动到桌面或其他应用的文件会按导出流程处理。

也可以剪切项目，打开目标目录后粘贴。跨设备或跨文件系统的移动可能需要先复制、再删除源文件，耗时会更长；进行中的操作可在状态中心查看。

**从 Fiex 外部拖入**的项目会复制到 Fiex 当前文件夹。拖出 Fiex 的项目则会导出到目标应用或位置。若目标应用不接受该文件类型，改用复制/粘贴或系统文件管理器。

## 创建副本

要在当前本地目录制作一份副本，选择项目并打开上下文菜单，选择“创建副本”。Fiex 会将副本放在当前目录，并在名称中增加后缀以区分原件。复制目录时不要把目标目录选成该目录自身或其子目录。

## 放入废纸篓与永久删除

### 放入废纸篓

选择文件后使用“移到废纸篓”或“删除”命令。支持的本地位置会将项目移入系统废纸篓；Fiex 的 Trash 位置中也可管理已删除项目。外接卷、网络位置或虚拟位置能否恢复，取决于该位置提供的能力。

### 永久删除

永久删除会绕过废纸篓，通常无法撤销。打开上下文菜单的“更多”子菜单，在最底部选择红色“彻底删除”，并按界面要求确认。请先核对所选项目和数量，再执行。

## 查看操作进度与撤销

小型操作会直接完成。复制、移动或批量任务如果需要更长时间，可从状态中心查看进度、来源和目标；支持取消的任务可在这里停止。Fiex 为部分本次运行中的文件操作提供撤销入口，但不能保证所有系统或插件操作都可撤销。关闭应用后，不应依赖撤销记录仍然存在。

遇到只读、权限不足或目标冲突时，查看界面中的具体错误提示；若来源是远程连接，确认连接仍然有效。
