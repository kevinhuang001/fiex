# 文件操作与拖放

## 基本操作

Fiex 支持新建文件和文件夹、重命名、复制、剪切、粘贴、复制副本、移动到废纸篓，以及当前会话中的撤销。重命名直接在文件项上完成。新建文件夹后会立即创建并进入名称编辑状态。

复制和移动遇到同名目标时，会显示冲突处理选项。你可以替换、跳过、逐项比较，或同时保留两个版本；保留两者时目标副本会获得唯一名称。跨卷移动会先复制，复制成功后才删除来源。

撤销和剪贴板状态由 Fiex 会话管理。当前会话结束后，不应把它们视为系统级历史记录。

## 拖放规则

| 拖放位置                                                  | 默认行为                 |
| --------------------------------------------------------- | ------------------------ |
| Fiex 内把文件或文件夹拖到另一个目录                       | 移动                     |
| Fiex 内拖放并按住 Option / Alt（部分键位配置也支持 Ctrl） | 复制                     |
| Fiex 不同窗口之间拖放                                     | 移动                     |
| 从其他应用拖入 Fiex                                       | 复制到当前目录，保留来源 |
| 从 Fiex 拖到 Finder、资源管理器或桌面                     | 复制，保留 Fiex 中的来源 |
| 把文件夹拖到侧边栏收藏区域                                | 添加收藏                 |

对于浏览器上传目标等外部应用，Fiex 使用复制语义，避免拖出时删除原文件。虚拟文件系统之间的操作可能经过能力预检；最终支持哪些操作取决于当前 provider 声明的能力。

## 删除与恢复

键盘删除快捷键会直接将所选项目移入系统废纸篓；右键菜单的删除动作会显示确认。进入 Fiex 的废纸篓/回收站位置后，可使用恢复、永久删除或清空操作。具体可见性与恢复能力受操作系统和系统权限影响。

macOS 恢复废纸篓项目时，Fiex 会优先使用 Finder 保存的原位置和原文件名（Put Back 信息）。如果这些信息不可用，Fiex 会打开自己的文件夹选择器，让你指定恢复位置。APFS Data 卷路径会转换为用户可见的目录路径。

“从最近使用中移除”只删除最近使用列表中的记录，不删除原始文件。
