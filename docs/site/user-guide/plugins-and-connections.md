# 插件与远程连接

## 安装插件

插件是可选组件，不会随 Fiex 默认预装。通过工具栏的插件入口打开管理界面，可查看、安装和管理当前平台可用的插件。插件市场只展示有适配当前平台的发布包的插件；列表内容随插件仓库的发布变化。

安装后，用户需要在 Core 管理的激活流程中查看插件声明并决定是否启用。只有实际需要时才授予对应文件、网络或命令能力。启用与权限是两个独立状态：插件启用不代表所有权限都已授予。

## WebDAV 与 SMB

官方插件仓库包含 WebDAV 和 SMB/NAS 连接实现。连接会作为 Fiex 的虚拟设备显示，不会创建操作系统级网络磁盘挂载。连接关闭不会自动清除本地缓存。

远程文件按需下载到本地缓存。界面中的“缓存到本地”用于获取文件副本；“始终保留在本地”用于固定文件或目录以支持离线使用和同步。取消缓存只清理未固定的缓存副本。缓存状态和后台同步周期可在相应界面/设置中查看与调整。实际协议能力由安装的插件版本决定。

连接凭据使用系统凭据存储；连接配置文件不保存明文密码。处理凭据时应只使用 Fiex 的连接界面和授权流程。

## 其他官方插件

官方插件仓库还包含 Git、压缩与校验、Office/数据预览、Google Drive、OpenList、Email、GPG、SSH、Windows Everything 搜索和主题等实现。不同插件的系统要求、权限和发布平台不相同，详见[官方插件仓库](https://github.com/kevinhuang001/fiex-official-plugins)及各插件说明。

插件可能请求网络域名或外部命令。授权前请阅读插件的用途和声明；参见[插件权限与安全边界](/reference/security)。
