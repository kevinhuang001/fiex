# 安装插件与连接服务

插件可以增加远程连接、预览和工具等能力。插件不是 Fiex 必需组件；只安装你需要、且愿意授权的插件。

## 可选插件能做什么

| 插件类别             | 常见用途                                                                                                                                 |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Git / Source Control | 查看仓库状态、暂存文件、提交和浏览提交历史；部分插件支持 push 或 fast-forward pull。详细步骤见[源代码管理](/user-guide/source-control)。 |
| WebDAV、SMB 等连接   | 将服务端目录显示在 Fiex 的连接/设备视图中；实际读写和离线能力由插件支持情况决定。                                                        |
| Archive              | 浏览、压缩或解压受支持的归档格式；格式列表以插件详情为准。                                                                               |
| Checksum             | 在隔离的插件面板中计算常见文件校验值。                                                                                                   |
| 其它搜索或预览       | 为主搜索或文件预览增加 provider；这些结果仍需通过 Fiex 的插件授权。                                                                      |

插件目录、可用平台和版本会变化。上表是功能类别，不保证每个安装包都预装或提供所有插件。

## 打开插件设置

在工具栏打开“插件”菜单，再选择“插件设置”。这里可以查看已安装插件、打开市场目录或从本机导入插件包。

![插件设置窗口，列出可用插件](/screenshots/plugin-manager.png)

_图：当前版本插件管理界面。市场内容和已安装插件会随版本变化。_

## 从插件目录安装

1. 在插件设置中打开“获取插件”。
2. 选择你需要的插件，阅读其说明和请求权限。
3. 按提示完成安装和启用。
4. 在首次启用的授权窗口检查权限类别与具体目标。取消授权不会授予权限；可取消单项权限后再继续。
5. 返回文件浏览窗口，按插件说明打开对应的连接或功能。

Fiex 发布包不会预装所有可选插件。插件目录是否能访问取决于网络和当前目录配置；若列表不可用，可使用本地导入流程。

## 从本机导入插件

1. 选择“导入插件”，选取插件包。
2. 检查导入确认窗口中的插件身份、版本和签名信息。
3. 确认身份与来源符合预期后，继续到权限审查窗口。
4. 逐项查看权限，取消不需要的权限，再决定是否启用。

![本机插件导入时的身份与签名审查](/screenshots/plugin-import-review.png)

_图：导入确认界面展示身份/签名信息。签名信息用于识别包的来源和完整性，不代表 Fiex 为插件背书，也不会替代权限审查。_

手动复制到插件目录的插件不会自动启用。请在插件设置中检查并手动启用；启用时仍需完成授权确认。

## 如何判断是否授权

授权窗口按用途展示权限，例如读取文件、写入/删除、网络连接或运行外部命令。只批准完成该插件用途所必需的项目。尤其是“运行命令”：被允许的外部程序以当前用户身份执行，可能访问插件文件 API 以外的资源。

几个重要原则：

- Manifest 声明权限，不等于用户已经批准。
- 已批准权限仍会受到当前操作范围和目标资源的限制。
- 官方插件和第三方插件遵守相同的授权流程。
- 插件包签名只帮助验证包身份与完整性，不证明其行为安全。
- 撤销权限后，再次调用相关功能时 Fiex 会重新询问或拒绝该调用。

可以在插件设置中查看、调整或移除已安装插件的授权。卸载插件会删除该插件的本地安装内容；它不会替你删除远程服务上的数据。

## 添加远程连接

若插件提供连接功能：

1. 从侧边栏或工具栏的连接入口选择“添加连接”。
2. 选择相应插件连接类型，填写它要求的服务器地址、账户或其他字段。
3. 按插件流程完成登录或授权。
4. 连接成功后，从侧边栏打开该连接。

连接位置在 Fiex 中以虚拟文件系统视图呈现，并非操作系统挂载盘。复制、删除、搜索和预览等命令取决于连接插件公布并实现的能力。离线时可以查看的缓存内容也取决于插件。

连接打不开时，先检查网络、账号授权是否过期，再从连接菜单编辑或删除该连接。删除连接入口不一定会删除云端文件或账号数据。

### 缓存与离线文件

连接提供的离线能力并不相同。对于支持文件缓存/同步的连接：

- 打开或预览文件可能先下载一份本地缓存；菜单里的“缓存到本地”也可下载但不固定为离线副本。
- “始终保留在本地”用于固定文件或文件夹；支持该行为的 provider 会在远端变化后更新本地内容，文件夹还可能递归固定子项。
- 普通缓存与固定副本是不同状态。远端版本变化时普通缓存可能失效并在下次打开时重新下载。
- 两端都发生修改时，Fiex 应显示冲突并等待你选择保留方式，不应默默覆盖。
- “取消缓存”只移除符合条件的本地副本，不代表删除远端项目。未同步修改或冲突中的副本可能不能取消。

列表里的缓存/上传徽标由当前连接返回。跨 provider 的行为可能不同；如果菜单没有缓存或同步动作，表示该位置没有公布相应能力。

更多内容见[插件权限与安全边界](/reference/security)及[插件开发手册](/developer/plugin-development)。
