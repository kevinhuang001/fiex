# 搜索与预览文件

## 搜索名称或文件内容

点击工具栏搜索框，输入要找的词。根据搜索入口和当前设置，可搜索当前目录范围或更广范围，并可切换按名称查找或查找文件内容。输入后 Fiex 会逐步显示找到的项目；结果可能在目录扫描过程中继续增加。

当前搜索直接遍历可访问位置，没有维护一个完整的后台内容索引。因此：

- 大目录、外接盘和远程连接可能需要更久；目录扫描时仍可等待结果更新。
- 可搜索结果最多显示 500 项。结果被截断时，缩小范围或使用更具体的关键词。
- 内容搜索只读取适合读取的文本文件，会跳过二进制文件；被系统权限保护的文件可能不会出现在结果中。
- 显示忽略规则会影响搜索范围。可在设置中管理被忽略的文件或目录。
- 应用包会作为一个项目显示，不会像普通目录一样深入递归搜索内部内容。

如果你只记得文件所在文件夹，可先打开那个文件夹再搜索，减少扫描范围。插件也可以提供搜索来源；插件结果会和同一次搜索的其他结果一起显示。

## 预览文件

选择文件后按预览快捷键，或在工具栏打开预览。支持的类型会在 Fiex 内显示内容；不能预览时，可以使用“打开方式”选择系统应用。

Fiex 内置支持常见图片、UTF-8 文本/代码和 PDF 预览。部分音视频预览依赖系统 WebView 的编解码器；即使文件不能在 Fiex 中播放，也可以从“打开方式”交给其他应用。

文本预览会按文本方式读取内容，不代表所有超大文件都适合整体打开。若内容看起来乱码或为空，先检查文件编码和是否为二进制文件。

## 打开文件而不是预览

双击文件会按 Fiex 的打开流程处理。上下文菜单里的“打开方式”可选择其他应用；点击此项会直接打开应用选择器。选择应用后，该次打开将使用你指定的程序。

## 插件提供的搜索与预览

安装并启用插件后，插件可能增加新的搜索来源或文件预览方式。Office 插件可预览 Word、Excel 和 PowerPoint 文件；在受支持的 `.docx`、`.xlsx` 或 `.pptx` 文件上，还可从右键菜单的“Office → 转换为 PDF”导出同目录 PDF。转换在本机由 Office 插件完成，任务成功后当前目录会刷新并显示 PDF。插件读取文件前仍需通过 Fiex 的权限检查；若你撤销了对应权限，下一次使用该能力时会重新提示。详见[插件与远程连接](/user-guide/plugins-and-connections)。
