# 搜索与预览

## 搜索

Core 的本地搜索会实时遍历当前文件系统，不维护持久化索引，也不在后台重建索引。搜索结果最多返回 500 项，并遵循设置中的“显示忽略”规则。常见构建目录或系统元数据可通过忽略规则隐藏。

应用包（例如 macOS 的 .app 或 .framework）可以作为搜索结果出现，但搜索不会递归扫描它们内部的内容。需要索引搜索或语义搜索时，可查看通过插件扩展的搜索来源；插件可用性以插件市场和对应版本为准。

## Quick Look 预览

选中文件后按空格打开预览。内置预览支持图片、音频、视频、UTF-8 文本/代码和 PDF。PDF 使用内置 PDF.js 渲染。视频和音频播放依赖当前系统 WebView 支持的格式。

应用程序显示系统原生图标。某种文件预览失败时，可以使用“打开”或“打开方式”交给系统应用处理。
